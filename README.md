A responsive and user-friendly web platform designed to manage and explore artwork and exhibition data. Built using HTML, CSS, PHP, and MySQL, this system allows Customer to browse gallery details and adminstrators to manage artworks and exhibitions efficiently.

Features

For Customers
- View gallery information and exhibitions
- Browse artwork with images and details

For Admins
- Admin login system
- Add, update, and delete artwork
- Manage exhibitions and artist info

Tech Stack

Frontend : HTML5, CSS – for building responsive and interactive user interfaces.

Backend : PHP – for handling server-side logic and database interaction.

Database : MySQL – to store information about artworks, exhibitions, and users.

Code Editor : VS Code
