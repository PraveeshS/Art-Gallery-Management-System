A responsive and user-friendly web platform designed to manage and explore artwork and exhibition data. Built using HTML, CSS, PHP, and MySQL, this system allows Customer to browse gallery details and adminstrators to manage artworks, artist and exhibitions informations efficiently.

Features

For Customers
- Customer login system for secure access
- View gallery information and detailed upcoming exhibitions
- Browse artwork details, including descriptions, and artist information

For Admins
- Admin login system
- Add, update, and delete artwork details
- Manage exhibitions and artist information

Tech Stack

Frontend : HTML5, CSS – for building responsive and interactive user interfaces.

Backend : PHP – for handling server-side logic and database interaction.

Database : MySQL – to store information about artworks, artist, exhibitions, and users.

Code Editor : Visual Studio Code (VS Code)
